Synthetic fixtures generated with Pillow 11.3.0 / libwebp, 2026-10-03:

- static.webp: 32 x 32 RGB, lossless, 38 bytes.
- animated.webp: two 32 x 32 RGBA frames, lossless, 100/200 ms, 144 bytes.
- high-compression.webp: 4096 x 4096 solid RGB, lossless, 706 bytes.

Original files are never transformed in production. The high-compression fixture
exercises the explicit container/frame/encoding-header validation path because
TwelveMonkeys 3.15.2 allocates a complete lossless raster and has a pre-sampling
expansion guard. The other fixtures exercise its real image decoding path. This
does not claim full compressed-bitstream validation for the structure-only path.

`public-key-encrypted.pdf` is an actual PDFBox 3.0.8 Adobe.PubSec document with a
synthetic self-signed recipient certificate, generated by
`GeneratePublicKeyPdf.java` using already available BouncyCastle 1.76 tool jars.
It contains one blank page; the private key was never written to disk. Those
generation tools are not production dependencies. The application verifies the
observable encrypted envelope without certificates/passwords/private-content
access. The file also exercises compressed object-stream handling produced by
PDFBox's default save.
