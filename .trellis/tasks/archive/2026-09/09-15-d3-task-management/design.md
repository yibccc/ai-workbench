# 技术设计

- 不采用 DDD、六边形架构或全局技术分层；继续使用按业务功能分包，`task` 包内放置 Controller、Service、Mapper、DTO 与持久化行类型，Mapper XML 放在对应 resources 路径。
- 待办状态初期使用 `PENDING` 与 `COMPLETED`，优先级使用固定枚举。
- 使用版本字段做乐观并发控制。
- 项目引用稳定标识；归档项目可出现在历史待办中，但不能用于新自动匹配。
- 查询 API 以明确筛选参数表达状态、项目、优先级和截止日期。
- 已应用的 V1 迁移不可回写；若当前 `todo_items` 状态或字段与本设计不一致，必须通过后续 Flyway 迁移演进。
