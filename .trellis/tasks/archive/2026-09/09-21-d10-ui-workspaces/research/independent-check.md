# 四工作区独立检查

## 范围与结论

检查正式前端、共享弹窗、分页及实时恢复路径，结合子任务需求、技术设计、实施计划、changes 指引和前后端规范。未发现本次接入需要额外修复的产品问题；未修改业务代码。

- RetainedView 首次访问挂载，隐藏后保留表单和订阅；TasksPanel 使用 refreshKey 更新列表，保留筛选。
- 导航采用 hashchange 与合法工作区白名单，未知 hash 回到记录；skip-link 直接聚焦 main，不污染路由。导航后更新标题和主区域焦点。
- 记录和任务抽屉使用共享原生 dialog；取消/放弃确认、IME 保护、提交锁、焦点恢复路径完整。写成功后的列表刷新由列表状态处理，不把已完成写入作为失败重新提交。
- 日报/周报保留独立编辑状态；历史分页和日期变化确认未保存内容，来源分页独立，保存响应核对当前选中版本和最新草稿。
- ProjectPicker 展示完整项目集合，允许保留已有归档归属，新建时归档项目校验仍生效；项目管理使用真实分页、搜索和包含归档筛选。
- 正式 src 无预览 mock 引入、演示数据标记或原生 prompt/confirm/alert；API 模块和 realtime.ts 无本轮差异。
