# 站内广场与私有附件

## 目标与价值

已有工作台用户可以把自己选择的今日成果、动态和博客分享给其他登录成员，同时保持原始工作记录与草稿私有。直接复用已经批准的 R2 原型布局和可用源码，在现有工程中接真实数据、鉴权与持久化。

本轮使用 WSL Docker RustFS 提供私有对象存储。阿里云凭据尚未申请，本轮不实现或调用阿里云 API；固定统一附件合同，为将来增加阿里云适配器和配置切换留出边界。

## 验收标准

沿用源 AC-01～22，不重新编号；完整原始条件见 `research/handoff/r3/requirements.md` 第 4 节，场景见同目录 `acceptance.md`。以下为本地正式目标；只有 AC-21 的实际供应商按用户本轮要求改为 RustFS，其余源条件完整继承。

- [x] **AC-01**：B/ADMIN 越权访问 A 私有记录、草稿或来源返回 404，无局部写入；发布响应不含原始来源关联和账户敏感字段。
- [x] **AC-02**：三类发布在列表/详情及公开作者主页可读，草稿不可见；作者退出后仍可读；其他用户不能编辑。
- [x] **AC-03**：指定日期的本人完整候选集合可分页；默认无选择，跨至少两页保留；只公开所选字段，项目名/具体时刻/未选项默认排除；专注合计额外勾选且不计任务完成数；日期切换无串选，同日允许多篇。
- [x] **AC-04**：修改/补记/删除来源或保存修改稿不改变读者正文；显式发布更新才替换正文/附件；每次发布保留历史，读者只读当前版本；首次发布时间不重置、不重新置顶，界面明确保存与发布区别。
- [x] **AC-05**：撤回/下架生效后列表消失，旧详情新请求返回 404且无标题/正文/附件；ADMIN 下架必须理由与审计，作者不能绕过，下架无恢复流程。不追回已下载内容或中断已授权开始的流。
- [x] **AC-06**：同逻辑发布重试只产生一次版本；过期写入返回明确 409，不静默覆盖；失败输入保留供重试。
- [x] **AC-07**：原五工作区往返保持既有草稿/筛选；专注控制器/声音不重建或重复注册；退出/失效/换号隔绝旧请求与通知；原记录、任务完成事务、专注进展、日报/周报与日期回归通过。
- [x] **AC-08**：受支持详情地址可直开/刷新，无保护内容闪现；正文/链接/文件名不可执行脚本；非法来源和 CSRF 写入拒绝且无局部修改。不得自行添加旧 hash 兼容层。
- [x] **AC-09**：匿名/失效读取广场、详情、作者资料、附件返回 401且无保护数据；真实 401 清空视图，网络故障/403/404不伪装成失效；后台读取不续期。
- [x] **AC-10**：登录后返回原受支持站内目标；撤回/下架只显示不可访问；外站或不允许目标不形成跳转。
- [x] **AC-11**：发布明确本站所有登录用户可见；无匿名入口，构造匿名 scope 被服务端拒绝且无匿名对象。
- [x] **AC-12**：广场、详情、作者主页无点赞/评论入口、计数、占位及业务 API。
- [x] **AC-13**：匿名附件读取 401，无文件名/大小/字节；B 读 A 草稿附件 404；作者经受保护入口读自己的就绪附件；读者仅读当前可见发布引用。
- [x] **AC-14**：撤回/下架或移除当前版本引用后，所有新读请求都不得返回旧附件字节/元数据，包括支持的 HEAD/条件/Range 路径；缓存、旧站内地址和云直连不可绕过。
- [x] **AC-15**：F1 发布时上传/保存 F2 仍只给读者 F1；显式更新后切为 F2，F1 对象不原地覆盖，F1不再对普通读者可见且保留历史引用。
- [x] **AC-16**：格式/大小/验证/中断/存储失败不形成就绪附件；含未就绪引用不可发布；失败文件可重试/移除，正文和其他附件保留，不能谎报上传成功。
- [x] **AC-17**：伪造附件 ID/对象标识不可绑定/删除他人对象；清理仅处理无当前发布/有效草稿/保留历史引用的孤立对象，和绑定竞争不误删；失败可重试，不设自动清理天数或用户总配额。
- [x] **AC-18**：仅白名单扩展名与真实格式一致的 JPG/JPEG、PNG、WebP、PDF、MD；明显伪装拒绝，无自动转换。MD 按明确文本编码合同验证，不宣称能识别一切改名文本或保证无病毒。
- [x] **AC-19**：实际字节上限：图片 5,242,880、PDF 20,971,520、MD 1,048,576；每篇所有附件总计 10 个/52,428,800字节，等号允许，超 1字节或第11个拒绝；并发/重试不突破，重复同 ID计一次、不同ID分计；历史附件不计当前额度但保留对象。
- [x] **AC-20**：图片正文显示及可关闭大图；PDF/MD 只经后端下载，无阅读器/预览，MD 不导入正文；真实下载字节/文件名正确，失败可重试且正文不消失。
- [x] **AC-21（本轮适配）**：上传/图片/下载全经后端；RustFS 私有桶匿名读取测试对象失败；先验证会话与当前引用再流式读取；响应无长期凭据、云 URL/预签名或云重定向。统一合同可供后续阿里云适配，但本轮不运行云 API、创建云资源或声称阿里云已验收。
- [x] **AC-22**：全部 R2 业务页面/状态与原型同视口对照，桌面/移动导航、区域顺序、卡片、编辑/附件、主要操作/弹窗位置一致；17图及源码共同覆盖，无演示身份/状态菜单/静态专注或虚构私有数据。字体回退/真实内容自然差异允许，主要布局改变须确认。

## 非目标与约束

不实现匿名公开、点赞评论、关注私信、推荐热榜、开放注册、通知举报、管理员恢复、云端 API/资源、浏览器直传或预签名、公共 CDN、多云运行、用户总配额、自动定时清理、Office/TXT/压缩包/音视频/GIF/SVG/HEIC、格式转换、MD导入、PDF/MD在线预览、AI润色或附件送模型、独立文件服务。

不重写既有工作台，不修改已应用迁移，不放开任何原业务 owner 条件，不加入旧版本回退/兼容迁移/功能开关/默认禁用。尚未批准 commit/push/PR/发布；后续批准执行覆盖规划范围内实现与验证，遇到非阻塞问题留到最后，新增范围或具体兼容方案仍需单独同意。
