# 五分钟演示与独立验收

按 README 启动工作台：Windows 入口为 http://127.0.0.1:5173，Docker 默认入口为 http://127.0.0.1:8088。下面的演示会新增示例数据。AI 输入和报告生成按实际调用计费；每个场景最多尝试3次，失败时记录错误码。

1. **0:00—1:00** 新建项目“演示-本机交付-日期”，手工添加“已完成本机启动检查”，确认新建内容在首位；切换记录日期后再切回来，验证数据仍可见。
2. **1:00—2:00** 输入“今天完成演示项目的启动检查，明天继续整理演示说明”，Ctrl+Enter 提交；等待实时结果，核对生成的记录与待办；不匹配的项目手动指定。
3. **2:00—3:00** 完成示例待办并填写结果，检查自动记录；重开再完成，检查当前成果没有重复。观察统一弹窗、多行结果和分页。
4. **3:00—4:00** 手动选择当天生成日报，核对来源，编辑保存再复制。可再生成一个版本并删除其中一份，确认原记录仍保留。
5. **4:00—5:00** 选择本周任意日期生成自然周报告，核对周一至周日和引用来源；填写人工补充、保存和复制。记录从开始生成到修改完成的真实耗时，与原手工耗时对比。

独立重启验收：停止脚本→启动脚本→确认原文、记录、待办、报告仍在；补录一条并生成报告，将结果和错误信息记入交付记录。

演示结束后，可删除示例待办、手工记录和日报，归档演示项目。周报版本与来源快照会保留。也可以使用已有真实工作内容走完上述流程。
