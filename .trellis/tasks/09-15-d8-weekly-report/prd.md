# 周报与版本保护

## Goal

生成有事实来源的自然周周报，并保护用户编辑稿、历史版本和来源快照。

## Requirements

- 默认周期为周一 00:00 至下周一 00:00 前，按 Asia/Shanghai 计算。
- 固定输出“本周完成、进行中与阻碍、下周计划”三段。
- 无期限待办不自动成为下周承诺；无依据不补造。
- 重新生成创建新版本，旧正文和旧来源快照保持不变。

## Acceptance Criteria

- [ ] 周报可生成、编辑、保存和复制，并能逐项查看来源。
- [ ] 补录记录后重新生成产生新版本，旧稿仍可访问且内容不变。
- [ ] 历史周期、项目改名和重复成果的处理符合来源快照规则。
- [ ] 记录一次手工整理与工作台生成加修改的真实耗时对比。

## Coverage

F07、F08、F10；A10—A12、G02—G03。
