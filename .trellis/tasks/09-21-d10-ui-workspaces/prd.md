# 四工作区前端改版与真实接口联调

## Goal

基于changes源码补丁接入四工作区、按需表单与编辑抽屉，核对后端兼容并完成真实隔离环境回归

## Requirements

- 用户追加可读性反馈：整体字号增大一档，正文/输入以16px为基准，辅助说明清晰可读，移动端导航和分页保持完整可操作。

- 以 changes/workbench-refactor-guide.md、workbench-ui-refactor.zip 中正式src与预览为依据，采用浅中性色和紫色强调色。
- 工作记录默认入口；桌面侧栏/移动紧凑导航进入工作记录、待办任务、工作汇报、项目管理四工作区。
- AI快记与手工录入按需切换；待办列表优先，新建/编辑用右侧抽屉，手机全屏。
- 已访问页面切走保留草稿、筛选和实时请求；用刷新令牌更新数据，避免key重挂载清空待办上下文。
- 项目选择单行并可访问全部已加载项目；项目管理独立，支持分页、搜索、归档筛选。
- 报告正文/来源分主次布局；保留日报删除、版本锁、人工补充、来源分页、未保存确认和WS恢复。
- Ctrl/Command+Enter、IME组合输入保护、防重提交、加载/空态/错误重试及焦点恢复可用。
- 正式运行使用现有API/真实持久化和模型配置；演示mock仅保留在changes参考中。
- 保留当前依赖锁与Vite代理/Docker配置；后端只在可复现接口缺口时做最小变更。

- [x] 四工作区与参考预览一致，320/390/768/1024/1440宽度无横向溢出，编辑抽屉可用。
- [x] 工作区及日报/周报切换保留草稿，日期/版本变化前确认，AI完成后任务筛选保留。
- [x] 记录、待办、项目、AI输入、日报/周报和删除/撤销用例在隔离真实后端通过。
- [x] 超过50项目可选，分页和加载/错误/重试/迟到响应合同保留。
- [x] 完整TypeScript、lint、生产构建、浏览器回归通过；后端改动需求有代码/测试依据。
